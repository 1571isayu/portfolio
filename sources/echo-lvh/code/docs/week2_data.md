# 第 2 週：訓練資料擷取

- 程式：`ml/03_extract_frames.py`（可中斷重跑，已存在的圖會跳過）
- 抽樣：train 2,400 · val 300 · test 325（全部官方 test），失敗 0 支
- 處理：取標註那一格 → 灰階 → 右下補黑邊成正方形（不變形）→ 縮成 256×256
- 輸出：`data/echolvh_256.zip`（39 MB），內含 `images/*.png` 與 `labels.csv`
- `labels.csv` 欄位：4 個點在 256×256 上的 x,y；IVSd/LVIDd/LVPWd（cm）；`cm_per_px_256`（每個像素幾 cm）
- 驗證：用座標反算三個量測值，與醫師數值平均差 < 0.05 mm
- **重要尺度**：256×256 圖上 1 px ≈ 0.96 mm → 目標誤差 ≤ 3 mm ≈ 模型點位誤差約 3 px 以內

# 第 3 週：模型訓練筆記本

- 筆記本：`ml/04_train_keypoints.ipynb`（在 Google Colab 開啟，T4 GPU）
- 模型：U-Net，編碼器為 ImageNet 預訓練 ResNet18，輸出 4 通道熱力圖
- 損失：空間 softmax 交叉熵（目標為以標註點為中心、σ=2 px 的高斯分布）
  - 一開始用加權 MSE，過擬合測試時 loss 卡住、模型輸出全 0（heatmap collapse）→ 改為 softmax 交叉熵後，32 張圖可學到 0.4 mm
- 本機 CPU 小規模驗證（480 張訓練、無預訓練、2 輪）：val MAE IVSd 2.6 / LVIDd 3.7 / LVPWd 1.6 mm

## 第一版模型結果（v1，2,400 張訓練，ResNet18 U-Net，40 輪，最佳在第 17 輪）
| 量測 | MAE (mm) | R² | 原論文 MAE (mm) |
| --- | --- | --- | --- |
| IVSd | 1.75 | 0.56 | 1.4 |
| LVIDd | 2.84 | 0.69 | 2.4 |
| LVPWd | 1.74 | 0.28 | 1.2 |

- 肥厚判斷（≥ 1.1 cm）：準確率 82.2%、敏感度 86.8%、特異度 73.5%（test 325 張）
- 觀察：最佳在第 17 輪之後 val 不再進步 → 資料量是瓶頸；R² 偏低因厚度範圍窄、且 256 px 下 1 px ≈ 1 mm

# 第 4 週：資料量實驗（v2）
- 擷取全部可用訓練資料：train 9,756 張（v1 的 4 倍），val 300、test 325 **與 v1 完全相同** → 可公平比較
- 打包：`data/echolvh_256_full.zip`（137 MB）；v1 的標註備份在 `data/labels_v1_2400.csv`
- 擷取程式新增 `--shard k/n` 平行擷取與 `--no-zip`
- 筆記本：`ZIP_NAME='echolvh_256_full.zip'`、`RUN_NAME='v2_full'`、`EPOCHS=25`，模型存在 `checkpoints/v2_full/`

## 第二版模型結果（v2，9,756 張訓練，25 輪，最佳在第 8 輪；test 與 v1 相同 325 張）
| 量測 | v1 MAE (mm) | v2 MAE (mm) | v1 R² | v2 R² | 原論文 MAE (mm) |
| --- | --- | --- | --- | --- | --- |
| LVPWd | 1.74 | 1.46 | 0.28 | 0.44 | 1.2 |
| LVIDd | 2.84 | 2.31 | 0.69 | 0.78 | 2.4 |
| IVSd | 1.75 | 1.74 | 0.56 | 0.52 | 1.4 |

- 肥厚判斷：準確率 81.2%、敏感度 86.3%、特異度 71.7%（v1：82.2% / 86.8% / 73.5%；差 1% ≈ 3 張，屬誤差範圍）
- 結論：資料量 ×4 → LVPWd 誤差 −16%、LVIDd −19%（優於原論文）；IVSd 不變 → 瓶頸可能是解析度（256 px 下心室中隔約 10 px）
- 最佳在第 8 輪 → 之後過擬合；下一步可試 384 解析度（方案 B）
- 後端改用 v2 的 best.pt

# 模型改進 v3：消融實驗（ml/06_train_v3.ipynb）
| 版本 | 改動 | 資料 |
| --- | --- | --- |
| v3a | v2 + 厚度損失（soft-argmax 算三段長度，L1 mm，權重 0.2，第 3 輪起）+ 強化增強（gamma、模糊、斑點雜訊、旋轉 ±12°、縮放 0.85–1.15）+ 提早停止（patience 6） | 256 |
| v3b | v3a + 解析度 384（1 px：0.96 → 0.64 mm） | 384 |
| v3c | v3b + ResNet34 | 384 |
- 每版都另外算 TTA（7 種平移/縮放、座標還原後取中位數）
- 384 資料：`data/echolvh_384_full.zip`（276 MB，10,381 張，切分與 256 相同；反算誤差 < 0.04 mm）
- 程式驗證：TTA 座標還原誤差 < 0.25 px；32 張過擬合測試可學到 0.6 mm
- 後端：解析度與骨幹自動從 best.pt 讀取；範例圖自動用相同解析度資料夾；`USE_TTA`（預設開，CPU 約 1 秒/張）

## v3 消融實驗結果（test 325 張，MAE mm）
| 版本 | LVPWd | LVIDd | IVSd | 平均 | 肥厚判斷準確率 |
| --- | --- | --- | --- | --- | --- |
| v2（基準） | 1.46 | 2.31 | 1.74 | 1.84 | 81.2% |
| v3a（厚度損失＋強增強＋提早停止） | 1.38 | 2.23 | 1.50 | 1.71 | 83.1% |
| v3a + TTA | 1.38 | 2.23 | 1.51 | 1.71 | 81.8% |
| v3b（＋384） | 1.32 | 2.31 | 1.70 | 1.77 | 83.4% |
| v3b + TTA | 1.29 | 2.27 | 1.68 | 1.75 | 84.6% |
| **v3d（v3a + ResNet34，256）** | **1.24** | **2.14** | 1.52 | **1.64** | **85.2%** |
| v3d + TTA | 1.26 | 2.15 | 1.53 | 1.65 | 83.4% |
- **最終採用 v3d**：相較 v2，LVPWd −15%、IVSd −13%、LVIDd −7%，肥厚判斷 81.2% → 85.2%
- ResNet34（更強骨幹）主要改善 LVPWd、LVIDd；與原論文相比 LVIDd 較佳（2.14 vs 2.4）、LVPWd 相當（1.24 vs 1.2）、IVSd 接近（1.52 vs 1.4）
- 厚度損失等訓練改進最有效：IVSd −14%（1.74 → 1.50），且資料量實驗中 IVSd 從未改善 → 瓶頸在訓練目標
- 384 解析度：LVPWd 小幅改善，但 IVSd 變差 → 解析度不是 IVSd 的瓶頸（推測：相對感受野變小、超參數依 256 調整）
- TTA：幾乎無效果（≤ 0.03 mm），且 CPU 推論慢約 6 倍 → 關閉
- 與原論文（1.2 / 2.4 / 1.4 mm）：LVIDd 已優於論文；IVSd、LVPWd 接近
- 部署：後端改用 **v3d**（256、ResNet34、USE_TTA=0）
